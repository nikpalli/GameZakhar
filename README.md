# Мотокросс Захара 3D 🏍️

3D-игра с открытым миром в духе GTA: Захар (бирюзовый шлем, очки, джерси с чёрными полосами)
гуляет пешком, садится на белый питбайк и гоняет по холмам, деревне, трассе с трамплинами.

**Как запустить:** открыть `index.html` в браузере (Chrome/Edge/Safari). Интернет не нужен —
Three.js лежит в `lib/`.

## Что есть
- открытый мир 800×800 м: холмы, лес, грунтовки с лужами (отражают небо), деревня как на фото —
  гаражи с навесом, дом с красной крышей, самосвал, ЛЭП, бело-синее здание
- ходьба/бег пешком, сесть/слезть с мотоцикла (**E**)
- физика мотоцикла: наклон в поворотах, скольжение в лужах, прыжки с трамплинов и столов
- трюки: прыжки и **сальто назад** (держи **S** в прыжке) — за них деньги
- машины ездят по дорогам, сигналят и останавливаются перед Захаром
- 3 миссии (жёлтые маркеры): «Гонка по трассе», «Каскадёр», «Срочная посылка»
- 21 звезда, деньги, радар, рекорд гонки сохраняется
- управление с телефона: джойстик и кнопки

## Управление (клавиатура)
| | |
|---|---|
| WASD / стрелки | ходить / газ, тормоз, руль |
| Мышь | камера (клик по экрану — захват мыши) |
| E | сесть / слезть |
| Пробел | прыжок |
| Shift | бег |
| S в прыжке | сальто назад |
| R | поставить мотоцикл |
| M | звук |

Старая 2D-версия: `2d.html`.
