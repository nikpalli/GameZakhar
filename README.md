# Мотокросс Захара 🏍️

Браузерная игра: Захар в бирюзовом шлеме и джерси катается на белом питбайке по карте с грунтовками, лужами, гаражами и деревьями.

**Как запустить:** открыть `index.html` в браузере (работает на компьютере и на телефоне).

## Управление
| Действие | Клавиатура | Телефон |
|---|---|---|
| Газ | ↑ / W | ГАЗ |
| Тормоз / назад | ↓ / S | ТОРМОЗ |
| Руль | ← → / A D | ◀ ▶ |
| Прыжок | Пробел | ПРЫГ |
| Заново | R | ↺ |
| Звук | M | 🔊 |

## Что есть в игре
- большая карта с кольцевой трассой, развилками и двором с гаражами
- лужи — скользко и брызги во все стороны, на траве медленнее
- 6 трамплинов, очки за прыжки
- 44 звезды на карте
- круги на время через флажки, лучший круг сохраняется
- миникарта и стрелка к следующему флажку
